# 🎓 Student Performance Prediction System

## 📌 Project Overview

Student Performance Prediction System is a Machine Learning based web application that predicts student performance using academic details like Study Hours, Attendance, Internal Marks, and Assignment Marks.

The system helps to analyze student performance and provides prediction results using a trained Machine Learning model.

---

## 🚀 Features

- 👤 Student Registration
- 🔐 Student Login
- 📊 Student Dashboard
- 🤖 Machine Learning Performance Prediction
- 📈 Prediction History
- 👨‍💼 Admin Login
- 🧑‍🎓 Student Management
- 📋 View Prediction Details
- 💾 SQLite Database Integration
